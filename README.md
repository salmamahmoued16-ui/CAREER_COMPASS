# Career Compass (Backend)

Graduation project: a career guidance application that helps students identify suitable career paths based on their interests, skills, needs, and personal information.

This repository contains the backend part, built with Laravel. The mobile app, AI, and UI/UX parts were developed by other team members.

## My Role
Backend Developer

- Built the backend with PHP and Laravel
- Designed and managed the MySQL database and its relationships
- Developed RESTful APIs for frontend-backend communication
- Implemented data validation and business logic
- Applied MVC architecture

## Tech Stack
PHP, Laravel, MySQL, REST APIs

## Setup
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
